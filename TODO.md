- [ ] **`/ask <model> <prompt>` — one-shot delegation to any model without moving the session context** (2026-09-09, Martin's request; mechanism measured, not inferred) — **the capability already exists and is undocumented**: `claude -p "<prompt>" --model <fable|opus|sonnet|haiku> --output-format json` runs a one-shot in a fresh session and returns the text plus `modelUsage` naming the model actually served (verified: `claude-haiku-4-5-20251001`). No context transfer, no session switch. So this is a thin wrapper — a `devcontainer/commands/ask.md` that shells out, parses the JSON, returns the answer and reports tokens — plus the standing consent gate for the credit-billed rung (`--model fable` must never fire without explicit per-task authorisation, per CLAUDE.md non-goals). The OpenAI half is `codex exec -m <model>` and waits on the codex slot.
  **The measured catch, which inverts the intuition:** a one-shot is NOT cheap. Four probes on Haiku — default 21,559 created + 7,517 read; `--system-prompt "..."` **27,385 created + 0 read** (replacing the system prompt LOSES the cached prefix and costs more, so do not do it); `--allowed-tools ""` 19,408 + 7,264. So there is a **~27k-token floor per call** that no flag tried collapses — it is dominated by tool definitions, not the system prompt. Against that, a marginal turn in the current session pays nothing for a prefix that is already cached.
  **Design rule that follows: delegate on PAYLOAD SIZE, not task simplicity.** Sending a trivial question to Haiku costs ~27k Haiku tokens where the same question in-session costs a few hundred Opus ones — a net loss on carbon and quota. Delegation wins when the *bulk* tokens move to the cheaper model: summarising a large file, scanning a long log, a mechanical pass over a big diff. Encode that in the command's guidance or it will be used exactly backwards.
  **Carbon figures motivating this (CO5, 2026-09-09, UNVERIFIED — no primary source checked):** Fable 5.1 ~3.7x Astra, Opus 5 ~5x Astra, Opus 5 ~1.4x Fable 5.1. Worth sourcing before they appear in any user-facing claim; the design rule above holds regardless of their exact values.
